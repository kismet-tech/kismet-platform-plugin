# Prepare email drafts

1. Find the named audiences in the signed-in collection. Use their returned IDs and member counts. A saved audience's size can differ from the number eligible to receive a send.
2. Write the shared message once. Add the approved incentive only to its intended audience. Use a coupon, claim link, or booking URL only when the operator or an authorized tool supplies it.
3. Check which draft operation this connection offers. If it can save drafts, follow its schema to preview the intended audiences and copy. When the operator asked to save drafts for review, save the reviewed inputs as unscheduled drafts and report each returned ID alongside its audience. For a preview-only request, show the copy and stop.
4. If the connection cannot save a campaign, provide the two versions as copy the operator can use in the dashboard. Say which work still needs to be done there.
5. Sending or scheduling requires separate authorization. An unverified sender can block delivery while still allowing draft preparation.
