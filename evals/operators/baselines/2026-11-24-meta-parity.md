**Unaided discovery.** Sonny’s deterministic server turn read performance and attribution and rendered a Meta results card in 4/4 runs. Across eight ordinary local-model conversations through the compact MCP, zero retrieved the correct attribution response. Qwen3 4B read the advertising skill four times and asked whether to proceed. GPT-OSS 20B tried attribution with a rejected input, tried the data dictionary, tried SQL and read performance. Its performance-only answer gave spend and clicks for a scenario with four view-through purchases. Errors from unsupported fixture reads establish nothing about customer data.

**Evidence control.** The replay called the actual MCP route's search and execute handlers for the correct operation, and checked each result against Sonny's source object. Eight additional local-model conversations began with those actual MCP responses already in context. Their scores measure interpretation. They receive no credit for discovering the operation. All conversations used the same prompt and selected collection. Each model ran once per case per condition.

**Scope.** This was a controlled source replay using the real Sonny server-turn and rendered account card, and the real external JSON-RPC route backed by synthetic manager identity and synthetic reads. The hosted answer-writing router, signed-in ChatGPT and real advertiser accounts were outside this comparison. The ordinary client sign-in probe reported no callable tools. The reduced discovery catalog lacks the live graph's example utterances. These are directional findings, not production success rates.

**Pre-merge review.** Accept the eval coverage separately from an attribution release decision. For the next contract revision, make the Meta booking question discover the scoped attribution read with its default period. Return the two provider windows, Kismet's named matches and receipt coverage as separate facts. Render an unknown receipt count explicitly when the field is missing. The neutral example for the first case is “Meta reported five purchases within seven days of a click and two within one day of a view. Kismet matched three click bookings and one view booking. Two of those four matches had purchase receipts.” The source cannot establish incremental lift.
